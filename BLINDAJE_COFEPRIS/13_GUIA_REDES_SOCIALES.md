# GUÍA DE REDES SOCIALES — CENTRO MIRË

**Para:** @centro.mire (Instagram, TikTok, Facebook, WhatsApp, web)
**Objetivo:** publicar sin exponerte ante COFEPRIS. La regla base: **comunica como centro de estética/belleza, nunca como clínica o consultorio médico.**

> Por qué importa: COFEPRIS también revisa la **publicidad digital**. La Ley General de Salud prohíbe la publicidad que atribuya cualidades **terapéuticas/médicas** o que **induzca a error**. Una sola historia diciendo "postquirúrgico" o "elimina grasa" puede usarse como evidencia en tu contra. Esta guía te da el lenguaje seguro.

---

## 1. REGLA DE ORO EN 3 FRASES
1. **No prometas curar, tratar, eliminar ni garantizar** nada médico.
2. **No te presentes como médica ni como clínica**; eres cosmiatra en un centro de estética.
3. **Lo "postquirúrgico" solo se menciona como cuidado complementario "por indicación de tu médico".**

---

## 2. PALABRAS PROHIBIDAS ⛔ vs. PALABRAS SEGURAS ✅

| ⛔ NO uses | ✅ Usa en su lugar |
|-----------|-------------------|
| Clínica médica / consultorio | Centro de estética / de belleza / spa estético |
| Doctora / Dra. / médico | Cosmiatra / especialista en cuidado de la piel |
| Paciente | Cliente / clienta |
| Tratamiento (en sentido médico) | Servicio / sesión / ritual estético |
| Postoperatorio / postquirúrgico (a secas) | Cuidado estético complementario **por indicación de tu médico** |
| Cirugía / lipo / reconstructiva | *(no aplica — no lo ofreces)* |
| Recuperación / sanar / cicatrización | Bienestar / confort / cuidado de la piel |
| Curar / cura / trata / combate | Ayuda a / favorece / contribuye a / mejora la apariencia de |
| Elimina grasa / celulitis / medidas | Reduce la **apariencia** de / mejora el contorno / difumina |
| Resultados garantizados / permanentes | Resultados que varían en cada persona |
| Adelgazante / quema grasa / detox médico | Sensación de ligereza / cuidado corporal |
| Bótox / rellenos / mesoterapia / enzimas / carboxiterapia | *(no aplica — no lo ofreces)* |
| Seroma / drenar seroma / herida | *(no aplica — es del médico)* |
| Dosis / aplicación / inyección | Sesión / aparatología estética |
| "Médicamente comprobado" / "sin riesgos" | *(evítalo — es publicidad engañosa)* |

> **Verbos seguros:** *ayuda a, favorece, contribuye, mejora la apariencia, cuida, hidrata, reafirma la sensación, consiente, relaja.*
> **Verbos peligrosos:** *cura, trata, elimina, combate, corrige, reconstruye, garantiza, recupera.*
